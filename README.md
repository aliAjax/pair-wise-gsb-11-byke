# 油站班次编制与替班交接台

- 行业：石油
- 技术栈：React、Vite、TypeScript（不引入额外依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在「油站设备巡检清单」基础上扩展为班次编制与替班交接台，数据整体保存在浏览器 `localStorage`（键 `dfwlfront-10-shift-desk:v1`），刷新后班次、交接、待办与版本保持一致。

## 业务规则

1. 每班登记**区域、日期时刻、值班岗位/值班人/所需资格、必到点**。
2. **整班成立判定**：人员在班内重复占岗、与其他班次时段重叠（含待确认替班对替班人的预定）、不具备所需资格或资格在班次日期已过期、时刻非法、无岗位或无必到点，任一命中则整班不成立，不能接班。
3. **缺岗与替班**：接班前后均可登记缺岗；替班人必须同区域、持本班日期有效的所需资格、本班时段空闲（含不能是其他岗位待确认的替班人）。
4. **交接责任**：替班需发起交接单；原值班人确认前责任不释放，确认后替班人接岗，可撤回恢复缺岗。
5. **接班冻结**：只有成立的班可接班，接班后名单与点位冻结（仅允许出勤/交接操作与点位结果登记）。
6. **漏检待办**：结班时未检点位自动生成待办并分派给同区域下一班；接班班次补检后自动关闭，结班时仍开放则自动改派。
7. **版本化调整**：结班后只能调整点位检查结果，必须填写原因，系统保存调整前整班快照并升版本号（接班冻结同时生成 v1 基线版本）。

## 分层结构（资料 / 判定 / 存储 / 页面分开）

- `src/domain/types.ts`：领域模型（班次、岗位、交接、待办、版本）。
- `src/domain/time.ts`：纯时间工具（日期键、区间重叠、资格有效期）。
- `src/domain/rules.ts`：**判定层**，纯函数——成立校验、替班候选人、责任人/占用口径、漏检与待办分派。
- `src/domain/actions.ts`：操作入口与业务守卫，组合判定层与存储层。
- `src/data/catalog.ts`：**资料层**——区域、资格、人员、必到点档案与内置示例数据。
- `src/data/storage.ts`：**存储层**——`localStorage` 读写 + 极简发布订阅，整棵状态一次写入。
- `src/ui/*` + `src/App.tsx`：**页面层**——React 组件，通过 `useSyncExternalStore` 订阅存储，不直接写判定逻辑。
