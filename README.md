# 油站班次编排与交接台

由「油站设备巡检清单」扩展而来的班次编制与替班交接台，纯前端最小闭环，数据保存在浏览器 localStorage。

- 行业：石油
- 技术栈：React、Vite、TypeScript（不新增依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

1. **班次登记**：每班登记区域、日期时刻、值班人、资格（排班时按班次日期做快照）与必到点。
2. **整班判定**：任一值班登记存在「同时段他班重叠」或「区域资格过期/缺失」，整班标记为不成立，不允许开班。
3. **缺岗替班**：仅可由同区域、资格有效且本班空闲（本班未排班、无时间相交的其他值班、非原值班人本人）的人员替班。
4. **交接责任**：替班人接班即冻结整班名单与点位；原值班人确认交接前责任不释放。
5. **漏检待办**：结班时所有「未检」必到点生成待办，转入同区域下一班；下一班也结班则继续顺延，直至补检完成。
6. **结班后调整**：已结班班次只允许修正检查结果，必须填写原因，调整前整班快照入历史版本，版本号 +1，快照只读。
7. **一致性**：班次、交接、待办、版本作为单一 JSON 原子读写，刷新后状态一致。

## 分层结构

| 目录 | 职责 |
| --- | --- |
| `src/data/` | 资料层：区域、人员资格、必到点静态资料与演示种子 |
| `src/domain/` | 判定层：类型与纯函数（资格、重叠、替班、交接、结班、版本） |
| `src/storage/` | 存储层：localStorage 单键读写、容错与重置 |
| `src/state/` | 状态层：把判定动作接到 React state 并原子落盘 |
| `src/components/` | 页面层：表单、班次卡、待办与人员台账 |
